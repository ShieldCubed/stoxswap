# StoxSwap

Non-custodial crypto exchange frontend powered by **StealthEX** widget.

- No KYC
- No account required
- 2000+ assets
- Partner commission: **0.4%**

## Setup

1. Register / login at [https://stealthex.io/pp/](https://stealthex.io/pp/)
2. Go to the **Widget** section and copy your Widget ID
3. Replace `YOUR_WIDGET_ID` in `widget.js`
4. Deploy to Vercel
